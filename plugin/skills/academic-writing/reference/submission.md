# Submission checklist

- [ ] Page limit respected (main text, as the venue defines it).
- [ ] Abstract within the venue's limit.
- [ ] Anonymized: no names, no identifying repository URLs (use an anonymous mirror), no self-identifying acknowledgements.
- [ ] Code linked from the paper is clean and documented, with an anonymous mirror for review.
- [ ] AI usage statement included if the venue requires it.
- [ ] No TODOs, colored text or comment boxes left in the submitted PDF.
- [ ] Camera-ready or arXiv version de-anonymized (authors, affiliations, acknowledgements). For arXiv, ideally one merged `.tex` file plus the style, `.bst` and `.bbl` files.
