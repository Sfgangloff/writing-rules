# Citations and references

- **Check every reference**: it exists, its metadata is correct, and it supports the sentence where it is cited. Never write a reference from memory without checking it.
- **When asked to add citations, go through the text sentence by sentence** and add one wherever a claim calls for it. Favor the literature of the paper's field; references from neighboring fields are welcome where relevant.
- A paragraph of factual claims needs at least one citation, unless it is purely the authors' own argument.
- Remove uncited entries from the `.bib` file, or move them to a separate file.
- When citing the state of the art, use current results and check that they are true.
