# Mathematical writing

- Formal definitions follow the standard textbook form, with a reference. Define every component (language, axioms, inference rules, what "decidable" means here).
- Introduce every symbol and its required properties before using it.
- Check that a definition and the remarks that follow it are consistent and unambiguous, and that the defined term appears in its definition.
- Use set notation where appropriate ({1, ..., n}), and say whether an object is a set or a relation.
- Use the definition environment only for definitions. If the content is too long for one, restructure it.
- One symbol per object, and no near-identical symbols without an explanation of their relation (see `clarity.md`).
